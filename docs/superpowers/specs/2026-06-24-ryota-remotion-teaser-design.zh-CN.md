# Ryota Remotion 展示视频设计规格

## 背景

目标是为个人网站 `www.ryota.top` 制作一支 Remotion 展示视频。

已确认方向：

- 视频格式：竖屏短视频，`9:16`
- 主版本时长：`15 秒`
- 风格：酷炫、电影感、科技感
- 展示重点：突出网站本身的视觉体验
- 主素材：`C:\Users\25384\Desktop\remotion素材\个人网页.mp4`
- 网站源码参考：`C:\Users\25384\Desktop\cl\web前端\scene_scroll_web_frontend\scene_scroll_web_frontend`
- 品牌/网址统一显示：`www.ryota.top`
- 音频策略：第一版不内置配音，但提供后续自配音可用的口播稿

该网站是一个原生 HTML、CSS、JavaScript 构建的电影感个人作品站，包含全屏视频场景、滚动驱动的场景切换、玻璃拟态卡片、相册展示、联系页、水波纹效果和音频控制。

## 推荐方案

第一版采用“录屏驱动 + Remotion 二次包装”的方式。

录屏素材作为主视觉底片，Remotion 负责竖屏构图、裁切、镜头运动、节奏剪辑、HUD 叠层、标题节拍、扫描线质感和结尾网址收束。这样可以最大限度保留网站真实的沉浸感，也避免在 Remotion 中重新实现复杂网页交互。

设计上要为后续混合增强版本预留扩展点。后续如果需要强化视觉冲击，可以从网站源码中取 `assets/scene1.mp4`、`assets/scene2.mp4`、`assets/scene3.mp4`、相册图片和项目 SVG，作为快速闪切或细节特写插入。

## 时间轴设计

### 0.0-1.2 秒：开场脉冲

视频从黑场或极暗画面开始，通过一次快速数字脉冲显露网站录屏。

画面文字：

- `CINEMATIC WEB EXPERIENCE`
- `www.ryota.top`

视觉处理：

- 快速透明度显现
- 轻微色差效果
- 细扫描线质感
- 画面边缘出现小型 HUD 标记

### 1.2-4.0 秒：第一印象

展示网站首页或进入场景，让观众感觉正在进入一个数字空间。

视觉处理：

- 缓慢推进
- 暗角
- 轻微镜头漂移
- 不遮挡核心内容的极简 HUD 线条

### 4.0-7.4 秒：滚动场景切换

利用录屏中的滚动或场景转换作为主要运动事件，在节拍点上剪切，并用克制的闪切强化转场。

画面文字：

- `SCROLL-DRIVEN SCENES`

视觉处理：

- 两到三次短闪切
- 边缘光扫过
- 在最强转场点做短促画面缩放冲击

### 7.4-10.8 秒：界面细节

展示项目卡片、玻璃面板或录屏中视觉最强的界面区域。

画面文字：

- `MOTION / GLASS / INTERACTION`

视觉处理：

- 局部放大裁切
- 轻微透视倾斜
- 用细 HUD 框线或角标追踪重点区域
- 控制噪点颗粒，避免遮挡网站内容

### 10.8-13.4 秒：体验快速掠过

快速展示相册、联系页或网站后段内容，把网站的丰富度压缩进一个短视觉段落。

视觉处理：

- 更快的剪辑节奏
- 在最强视觉帧短暂停留
- 预留后续源码资产闪切的位置

### 13.4-15.0 秒：网址收束

以深色、干净、稳定的结尾画面收束，突出网站地址。

画面文字：

- `www.ryota.top`
- 可选小字：`ENTER THE SITE`

视觉处理：

- 录屏淡出或缩回
- 网址清晰居中
- HUD 线条收束为稳定终帧

## 视觉系统

视频效果应服务于网站展示，而不是盖过网站本身。

建议使用：

- 深色电影感基底
- 青绿色高光
- 细技术线条
- 轻微扫描线
- 少量颗粒噪点
- 小型数字脉冲
- 只在转场节拍上使用轻微色差

避免使用：

- 遮挡网站内容的重度故障风
- 过多文字
- 过密 HUD 叠层
- 第一版就完整重建网站交互

## 验证方式

实现后需要检查：

- Remotion Studio 预览
- 第 1 秒附近的单帧渲染
- 结尾网址卡附近的单帧渲染
- 完整视频渲染回看，确认文字可读、网站内容未被遮挡、竖屏构图顺畅

成功标准：

- 视频能清楚传达这是 `www.ryota.top` 的视觉预告
- 网站视觉体验仍是主角
- 节奏适合竖屏短视频平台
- 结尾网址清晰、容易记住
- 结构能在后续接入源码资产，升级为混合增强版本
